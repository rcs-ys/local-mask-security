# P4: 暗号化 Store・監査・辞書高速化

## EncryptedMaskStore（AES-256-GCM）

平文の原文はメモリ上も暗号化して保持します（ `@noble/ciphers` ）。

```ts
import { createEncryptedMaskStore, createMaskEngine } from "@local-mask-security/core";

const key = crypto.getRandomValues(new Uint8Array(32));
const store = createEncryptedMaskStore({
  encryptionKey: key,
  ttlMs: 30 * 60 * 1000, // 默认 30 分
  hashOriginalsForAudit: true,
});

const engine = createMaskEngine({ locale: "ja", store });
```

- **TTL**: セッション単位。`lookup` / `register` で期限延長。期限切れセッションは自動削除。
- **`withSessionTtl(innerStore, ttlMs)`**: 既存 `InMemoryMaskStore` に TTL だけ付与するラッパー。

鍵は環境変数や KMS から Route Handler 起動時に注入してください（リポジトリに含めない）。

## 監査イベント

`onAudit` に渡る `AuditEvent` は **原文を含めない** 設計です。

```ts
import { createMaskEngine, createSafeAuditLogger } from "@local-mask-security/core";

const engine = createMaskEngine({
  locale: "ja",
  onAudit: createSafeAuditLogger({ sink: (e) => myLogger.info(e) }),
});
```

| フィールド | 内容 |
|------------|------|
| `timestamp` | ISO 8601 |
| `stats.byCategory` | カテゴリ別マスク件数 |
| `bySource` | regex / dictionary / rule / nlp 別 **検出** 件数（マージ前） |
| `missingTokenCount` | unmask 時の未知トークン数 |

`hashForAudit(text)` で SHA-256 を取り、`hashOriginalsForAudit` 有効時は `MaskEntry.hashedOriginal` に保存（ログには hash のみ）。

## 辞書: Aho-Corasick

`createDictionaryRegistry()` は默认 **`matcher: "auto"`** で、エントリが 1 件以上あれば Aho-Corasick を使用します（長文の辞書走査を高速化）。

```ts
createDictionaryRegistry({
  matcher: "aho-corasick", // 明示
  // matcher: "regex"       // 従来の RegExp 走査
});
```

検出 span の `meta.matcher` に `"aho-corasick"` / `"regex"` が入ります。
